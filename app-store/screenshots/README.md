# Screenshots — 6.7" iPhone (1290×2796px)

Place screenshots as PNG files in this folder. Required: 6-8 screenshots.

## Screenshot Checklist

1. `01-home-light.png` — Home dashboard: greeting, stats cards, weekly calendar
2. `02-today-dark.png` — Today schedule: job cards with rain delay button (Dark Mode)
3. `03-client-light.png` — Client detail: notes, gate codes, pet instructions
4. `04-invoices-light.png` — Invoices: paid/unpaid with mark-as-paid flow
5. `05-autopilot-dark.png` — AI chat drawer: typing a command
6. `06-dark-showcase.png` — Today tab in dark mode, full view
7. `07-pricing-light.png` — Landing page pricing cards
8. `08-compare-light.png` — Comparison page: MowFlow vs competitors

## How to Capture

1. Open Safari on iPhone → mowflow.pages.dev
2. Log in (or use Demo mode — "Continue with Demo")
3. Take screenshot (side button + volume up)
4. Save to Photos, AirDrop to Mac
5. Open in Preview → Tools → Adjust Size → 1290×2796
6. Save as PNG in this folder
