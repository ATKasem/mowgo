Synthesis from: today's pricing/intel captures (15:20, 11:17), QuoteIQ features page (fresh fetch), Housecall Pro roundup, Fieldproxy entrant, r/sweatystartup CRM-complaint thread (1htkeyt snippet), roadmap audit (07-31).

## Top 5 feature moves — prioritized

### 1. 📌 Online Booking Link (P0 — already roadmap, NOW validated as table-stakes)
- Every stack player now ships customer self-booking: QuoteIQ **InstaQuote + InstaSchedule** (customer self-quoting/scheduling), Housecall Pro **booking portal with real-time availability**, DoorstepHQ booking links, AutoRev **books jobs 24/7** (launched Jul 27).
- Roundups (myquoteiq.com top-8, ustechautomations 5-CRM list) list booking as a headline feature. MowGo without it is visibly behind on every comparison.
- **Action:** keep as #1 dev priority. `book.mowgo.app/[business-id]` → calendar → creates job. 1-2 days.

### 2. 🆕 Competitor import tool — "Switch in 10 minutes" (NEW — highest-leverage this month)
- Two churn pools are open RIGHT NOW: QuoteIQ axed its free tier (displaced users searching for alternatives — QuoteIQ-alternative page already in progress) and Jobber's promo **ended tonight Jul 31** (switcher wave starts Aug 1).
- **Feature:** CSV import (clients + recurring jobs) from Jobber/QuoteIQ/Yardbook + a `/switch` landing page pairing with the QuoteIQ-alternative page.
- **Cost:** ~1 day (file upload → parse → bulk create via existing client/job creation paths). Captures both waves with one build.

### 3. 🆕 Give Autopilot a public face (NEW — ships what already exists)
- AI front-office is THE battleground: AutoRev (Jul 27), Jobber AI Receptionist, QuoteIQ Virtual Call Team + "AI Autopilot", TurfHop Orbit AI, Servinix ($300 AI assistant, Sept 14).
- MowGo already HAS Autopilot (14 tools, function-calling, OpenRouter proxy) — but it's internal/unmarketed.
- **Feature:** embed Autopilot chat widget on landing page + booking-link flow → "AI that answers questions and books jobs" without building anything new. Public face before new AI builds.
- ⚠️ Do NOT claim "AI estimates from photos" (QuoteIQ's headline) — roadmap audit today confirmed MowGo doesn't have it. Keep Compare page honest (MowGo AI = ❌ on estimates).

### 4. 🆕 Rain-delay auto-SMS to clients (pull forward from roadmap "future")
- Rain delay is MowGo's #1 proven differentiator. Grassly has rain flags; SMS notification to clients on reschedule unverified across competitors.
- **Feature:** when a stop moves (rain delay one-tap), auto-text affected clients ("Your service moved to Thu 4pm"). Server already has Resend for invoice emails — same channel, ~0.5 day.
- Highest stickiness-per-effort on the board: it's the feature users can't get anywhere else.

### 5. 🆕 One-tap route sequencing (parity cheap win)
- Grassly Free, QuoteIQ, Fieldproxy (new entrant, "AI routing") all advertise route optimization. MowGo has drag-drop schedule + GPS nav but no auto-sequencing.
- **Feature:** "Optimize stop order" button (geo-sort today's stops). ~0.5 day. Kills a free-tier talking point cheaply.

## Defer (do not build yet)
- Client self-service portal → booking link supersedes it for MVP.
- Multi-crew fleet routing → post-revenue.
- Public API / Zapier → post-revenue.
- Inventory mgmt (QuoteIQ has it) → out of 1-3 person crew scope.

## ⚠️ Marketing-copy flag
- "No per-user fees" is NO LONGER unique: QuoteIQ explicitly markets "no per-user fees" at $29.99. MowGo's durable line must be the full stack: **flat price + no per-user fees + NO % of revenue** (QuoteIQ charges 1% tx fee on top of Stripe; Grassly 0.25-2%; TurfHop 3.9%+$0.30). Audit copy for standalone "no per-user fees" claims.
