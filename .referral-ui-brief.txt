# MowGo Referral Program — iOS + Android UI only

## Context
The referral program already exists on the backend and web:

**Schema:** `profiles.referral_code` (6-char, trigger-generated) + `profiles.referred_by`, `referrals` table (`referrer_id`, `referred_user_id`, `code_used`, `status: pending/earned`, `credit_applied`)
**Migrations:** `20260806160000_referrals.sql`, `20260806200000_referral_credit_claim.sql`
**RPCs:** `apply_referral_code(p_code)`, `referral_status()` (returns code/total_count/earned_count), `earn_referral_credit`, `claim_referral_credit`
**Web:** `client/src/lib/referrals.js` (stash+apply on signup), `Subscribe.jsx`, `Clients.jsx`, `Dashboard.jsx`, `Login.jsx`, `App.jsx`
**Backend:** Stripe webhook credits the referrer on checkout
