## 1. iOS CRITICAL — tier order for premium
File: `ios-native/MowGo/Views/Payments/PaymentView.swift` (SubscriptionPlanCard, ~line 152)

The `tierOrder` computed property (switch on `tier`: crew→2, solo→1, default→0) and `userTierOrder` (switch on `userTier.lowercased()`: crew→2, solo→1, default→0) do NOT handle "premium" — it falls to default 0. Consequences:
- A solo/crew user sees NO subscribe button on the Premium card (`canUpgrade = tierOrder > userTierOrder` = 0 > 1 = false).
- A premium user sees upgrade buttons on Solo/Crew cards.

Fix: add `case "premium": return 3` to BOTH switches (tierOrder and userTierOrder). Keep crew=2, solo=1, default=0.
