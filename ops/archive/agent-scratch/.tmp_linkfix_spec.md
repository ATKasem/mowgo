## Context: why these links are broken

The app uses HashRouter (URLs look like `mowgo.pages.dev/#/compare`). A plain `<a href="#anchor">` click changes the hash to `#anchor`, HashRouter interprets `anchor` as a ROUTE PATH, no route matches, and the catch-all `*` route inside RequireAuth redirects to `/app` → unauthenticated users get bounced to `/login`. So clicking these in-page anchor buttons sends users to the LOGIN page (or /app) instead of scrolling — a live "wrong URL" bug.

The KNOWN-GOOD pattern already exists in `client/src/pages/Compare.jsx:221-225`:
```jsx
<a
  href="#comparison"
  onClick={(e) => { e.preventDefault(); const el = document.getElementById('comparison'); if (el) { el.setAttribute('tabindex', '-1'); el.focus({ preventScroll: true }); el.scrollIntoView({ behavior: 'smooth' }); } }}
  className="..."
>{tr("See the full comparison")}</a>
```
Use this EXACT pattern (scrollIntoView + focus) for every anchor below.
