## KOTLIN COMPILE GOTCHAS (all hit in previous batches)
- No labeled returns in non-inline lambdas (`return@AlertDialog` is prohibited) — restructure with `val x = ...; if (x != null) { }`.
- Nullable mutable demo lists → wrap `(list ?: emptyList()).map {}`.
- Explicit `import java.time.Instant` when used.
- Top-level `private` = file-private (only matters if other files need it — dialogs reused cross-package must be public).
- `@OptIn(ExperimentalMaterial3Api::class)` for PullToRefreshBox/TopAppBar/etc.
- `collectAsStateWithLifecycle` / `viewModel()` imports (lifecycle-runtime-compose, lifecycle-viewmodel-compose).
- kotlinx.serialization: `@Serializable` request/response DTOs with `Json { ignoreUnknownKeys = true }`.
- PaymentSheet requires the calling context to be an Activity. `LocalContext.current` in a composable is usually an Activity in this app (MowGoActivity) — cast safely with `as? Activity` and handle null with an error message.
- Stripe PaymentSheet must be presented on the main thread — the ViewModel callback should hand the client secret to the composable (via state) and present from there, or use `withContext(Dispatchers.Main)`.
