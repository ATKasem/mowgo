## TASK 2 — send-push edge function: FCM routing (supabase/functions/send-push/index.ts)

Extend WITHOUT breaking the APNs path:
1. Load profile `device_token, fcm_token, device_platform` (select both token columns + platform).
2. Routing:
   - If `device_platform == "android"` (or fcm_token present): send via FCM v1.
   - Else if `device_token` present: APNs (existing path).
   - Else: `{"sent": false, "message": "No device token registered"}`.
3. **FCM v1 send** (`sendFcmPush(projectId, fcmToken, title, body)`):
   - Get OAuth2 access token from the service account JSON: build JWT (header `{"alg":"RS256","typ":"JWT"}`, claims `{"iss": client_email, "scope": "https://www.googleapis.com/auth/firebase.messaging", "aud": token_uri, "iat": now, "exp": now+3600}`), sign with RS256 using `crypto.subtle.importKey("pkcs8", ...)` (the private_key field — must convert the PEM to raw PKCS8 DER: strip header/footer/newlines, atob, Uint8Array; the APNs ES256 signing code at the top of this file already does PEM→DER for P-256 — mirror that pattern with `{ name: "RSASSA-PKCS1-v1_5", hash: "SHA-256" }`). Then POST `token_uri` with `application/x-www-form-urlencoded` body `grant_type=urn:ietf:params:oauth:grant-type:jwt-bearer&assertion=<jwt>` → `{"access_token": "..."}` (cache the token in a module-level var with expiry to avoid re-signing every call).
   - POST `https://fcm.googleapis.com/v1/projects/{project_id}/messages:send` with `Authorization: Bearer <access_token>`, body `{"message": {"token": fcmToken, "notification": {"title": title, "body": body}, "android": {"priority": "high"}}}`. 10s timeout.
   - Success: return `{success: true, status}`. Failure: return `{success: false, status, detail}` — parse the error body (FCM error codes: UNREGISTERED / INVALID_ARGUMENT → treat like APNs 410: clear the token). On 404/400 with UNREGISTERED, clear `fcm_token` (+ device_platform) in profiles.
4. Response shape stays `{sent: true/false, ...}` — add `channel: "fcm" | "apns"` in the response for clarity. Keep the 410-clearing behavior for APNs as-is.

## TASK 3 — Migration (NEW file `supabase/migrations/011_fcm_tokens.sql`)
```sql
-- Migration 011: FCM push tokens for Android
ALTER TABLE profiles ADD COLUMN IF NOT EXISTS fcm_token TEXT;
ALTER TABLE profiles ADD COLUMN IF NOT EXISTS device_platform TEXT;
COMMENT ON COLUMN profiles.fcm_token IS 'FCM registration token for Android push delivery.';
COMMENT ON COLUMN profiles.device_platform IS 'android | ios — which push channel the device token belongs to.';
GRANT UPDATE (fcm_token, device_platform) ON profiles TO authenticated;
```
