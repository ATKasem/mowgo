## THE BACKEND CONTRACT (already live — do NOT modify)

**Table `webhook_configs`** (after migrations 006/007/010): columns `id UUID PK`, `user_id UUID`, `url TEXT NOT NULL` (renamed from zapier_url), `events JSONB DEFAULT '[]'`, `is_active BOOL DEFAULT true`, `created_at TIMESTAMPTZ`, `secret TEXT NOT NULL` (64-char hex, was backfilled), `label TEXT`. RLS: user-scoped full CRUD (select/insert/update/delete with `auth.uid() = user_id`). Multiple endpoints per user allowed (no unique index).

**Dispatch API**: `POST https://mowgo.pages.dev/api/webhook-dispatch`, headers `Authorization: Bearer <supabase access token>` + Content-Type application/json, body `{"event": "...", "payload": {...}}`. Server: looks up active configs for the token's user, keeps those whose `events` array contains the event, POSTs HMAC-signed `{event, payload, timestamp}` to each URL. Returns `{delivered, failures, skipped}`. Non-2xx delivery = failure (server logs).

**Canonical event list** (web `WebhookSettings.jsx` AVAILABLE_EVENTS):
- `job.created` (Job Created — new job scheduled)
- `job.updated` (Job Updated — status/date/details change)
- `job.completed` (Job Completed — status → done)
- `invoice.paid` (Invoice Paid)
- `customer.created` (Customer Created — new client)
- `payment.failed` (Payment Failed — Stripe)
- `rain.delay.applied` (Rain Delay Applied)
- NATIVE ADDITION: `job.skipped` (iOS already fires this; include it in native event lists so users can subscribe)

**Payload shapes (web parity, snake_case keys):**
- job.created / job.updated: `{job_id, title, client_id, scheduled_date, status}`
- job.completed: `{job_id, title, client_id, scheduled_date, status: "done"}` (+ iOS adds client_name/email/phone, completed_at — keep iOS richer payload)
- invoice.paid: `{invoice_id, client_id, client_name, amount, paid_at}`
- customer.created: `{client_id, name, address, phone, email, rate}`
- job.skipped (iOS): `{job_id, job_title, client_name, client_email, client_phone, scheduled_date, skipped_at}`

**Secret generation**: 32 random bytes → 64-char lowercase hex (web: `crypto.getRandomValues`; Android: `SecureRandom`; iOS: `SecRandomCopyBytes` or 32 bytes of `UUID`-based randomness — use `SecRandomCopyBytes`).
