### DashboardViewModel (`ui/screens/dashboard/DashboardViewModel.kt`, new)

StateFlow<DashboardUiState> (loading / error(msg) / loaded). Data (all computed client-side, mirroring iOS):
- `today`: LocalDate.now() ISO string; helper `localDate(offsetDays)`.
- jobs = JobRepository.loadJobs(), invoices = InvoiceRepository.loadInvoices(), profile = ProfileRepository.loadProfile(), teamMembers = TeamRepository.loadTeamMembers() (see Task 2).
- todayJobs = jobs where scheduledDate == today.
- todayRevenue = sum of clientRate for today's jobs with status == done.
- outstanding = sum of amount for invoices with status unpaid (check Invoice model + demo data for status constant name — Batch 3 used Invoice.STATUS_PAID; unpaid is likely the other value, mirror it).
- weeklyJobs = jobs where scheduledDate in [today-6, today]; weeklyRevenue = sum of clientRate for weekly jobs done.
- activeClients = distinct clientId count for jobs in last 30 days; recurringClients = distinct clientId where recurrenceRule != null && != "none" && scheduledDate >= today.
- isOwner = profile.role == "owner" (default true when profile null → owner view).
- teamProgress: per team member, today's jobs where assignedTo == member.id (done/inProgress/total), plus an "Unassigned" row for jobs with assignedTo == null. Skip members with zero today jobs (iOS `guard !jobs.isEmpty else { continue }`).
- `refresh()` (pull-to-refresh), `inviteMember(email)`, `removeMember(member)` — delegate to TeamRepository; expose invite/remove error states.
- Role note: if profile.role is null (new DB row), treat as owner.

## KOTLIN COMPILE GOTCHAS (same list as Batch 4 — all hit before)

- NO labeled returns inside non-inline lambdas (`return@AlertDialog` / `return@onClick` are compile errors). Use local vals + if-checks.
- Nullable mutable demo lists: always wrap `(demoList ?: emptyList()).map { }` etc. Never `listOf(x) + nullableList` directly.
- `java.time.*` needs explicit imports (especially Instant); use `import java.time.LocalDate` etc.
- Top-level `private` = file-private: ClientFormDialog must lose `private` to be reusable across packages.
- PullToRefreshBox / FilterChip / TopAppBar / LazyVerticalGrid need `@OptIn(ExperimentalMaterial3Api::class)` where applicable.
- `collectAsStateWithLifecycle()` import: `androidx.lifecycle.compose.collectAsStateWithLifecycle`.
- ViewModels: plain ViewModel + MutableStateFlow + viewModelScope.launch.
- OkHttp: `okhttp3.OkHttpClient`, `Request.Builder()`, `RequestBody.create("application/json".toMediaType(), jsonString)` — imports from okhttp3.MediaType.Companion.toMediaType.
- kotlinx.serialization: Json { ignoreUnknownKeys = true } for parsing API responses (use a shared `Json` instance or build locally — check if SupabaseClientProvider exposes one; if not, create a private val).
- Material icons: `Icons.Filled.Dashboard` and `Icons.Outlined.Dashboard` come from material-icons-extended (wired). If unsure, `Icons.Filled.Home`.
- Do NOT add new dependencies to libs.versions.toml (okhttp, serialization, icons-extended all present).
